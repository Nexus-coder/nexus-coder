## 👨🏾‍💻 About Me

I'm a Computer Science student who enjoys turning ideas into real software.

My journey into programming started with **JavaScript in 2020**, which eventually led me into web development with **HTML, CSS and React**. Since then, my interests have grown far beyond frontend development.

These days you'll find me building **mobile apps, backend systems, real-time applications and AI-powered software**, while learning more about the engineering behind reliable and scalable systems.

I'm especially interested in the space between:

```text
idea → prototype → working product → reliable system
```

---

## 🚀 What I'm Into Right Now

🤖 **AI Engineering**
Exploring AI agents, tool calling, reasoning systems and especially **agent evaluation (evals)** — because getting an agent to work once is easy; getting it to work reliably is the interesting part.

📱 **Mobile Development**
Building cross-platform applications with **React Native, Expo and TypeScript**.

⚡ **Real-Time Systems**
Interested in event-driven architecture, WebSockets, **Pub/Sub systems, Redis** and building applications where things happen instantly.

🌐 **Full-Stack Development**
Working across frontend, APIs, authentication, databases, backend services and deployment.

📊 **Data & Machine Learning**
I enjoy working with data, finding patterns and understanding how useful insights can be extracted from it.

🧠 **Computer Science**
Continuing to go deeper into algorithms, data structures, databases, distributed systems and software architecture.
